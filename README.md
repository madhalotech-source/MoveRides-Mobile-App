# MoveRides-Mobile-App
A prototype Android ride-hailing application developed using **Delphi 12 FireMonkey (FMX)** and **SQLite**.

## About

MoveRides is a mobile application developed to demonstrate my skills in mobile application development using Delphi 12. The project includes user interface design, local database integration, and ride-booking functionality.

Although the payment gateway was planned, it was not completed before the project ended. This repository showcases the application's architecture, implementation, and user interface.

## Features

- Mobile application built with Delphi 12
- FireMonkey (FMX) user interface
- SQLite database integration
- Ride booking prototype
- Android deployment

## Technologies Used

- Delphi 12
- FireMonkey (FMX)
- Object Pascal
- SQLite
- FireDAC

## Tested On

Samsung Galaxy A14
